# עץ משפחה ישיבתי

The landing page for the Android app **עץ משפחה ישיבתי**, served by GitHub Pages.

- `index.html`, `style.css` — the whole site; static, no build step.
- `assets/` — the app icon, the Google Play feature graphic and the phone screenshots.

To update a screenshot, replace the file in `assets/screenshots/` and push.

[Google Play](https://play.google.com/store/apps/details?id=com.yoniSchwartz.YBMTree)
